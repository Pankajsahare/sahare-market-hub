# Bond Centre assets

- `bond-centre.js` — site हीच file load करते (minified). वाचता येणारा मूळ code private repo `Pankajsahare/advisor4u-site-source` मध्ये आहे; बदल तिथेच करायचे आणि तयार झालेली file इथे टाकायची.
- `bond-centre.css`, `logo.png` — styles आणि PDF साठी logo.

`main` वर `assets/` मध्ये बदल झाला की "Purge jsDelivr cache" workflow (`.github/workflows/purge_jsdelivr.yml`) CDN ताजं करतो, त्यामुळे site वर लगेच नवी file दिसते.
